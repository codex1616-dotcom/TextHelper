TextHelper: data and privacy

Version 10.0.14 · 4 November 2026

TextHelper has no analytics, advertising or browsing-history collection. Reading or selecting text does not send it to an external service.

Requests you initiate

Pressing Translate or Proofread sends the selected text to the service configured for that task: Google Translate, LanguageTool or your chosen AI provider. Pressing a search tool opens the selected text as a search query at Google, Wikipedia, YouTube or your configured HTTPS search address. The destination website receives that query under its own privacy policy.

AI design generation sends your description, validated theme parameters and the shared system prompt after a separate confirmation. Page text, page addresses and browser history are not included in design requests. API keys are sent only as authentication to their configured API endpoint. OpenRouter also forwards requests to the selected model provider; an Ollama cloud model may forward data beyond the local server. Paid APIs can charge your own balance.

Optional MyMemory translation

After Google fails, or if you select MyMemory in settings, the panel lets you confirm the source and target languages and explicitly send the selection to MyMemory / Translated. It does not switch services automatically. MyMemory needs no API key but imposes daily quotas and a 500 UTF-8 byte, one-paragraph request limit. Its policy permits long-term retention of text and sharing with translation partners. Read its data policy and terms before sending sensitive text. The extension only calls the GET lookup endpoint, never the contribution SET endpoint.

Local storage and retention

Settings, hidden-site hostnames and API credentials are stored locally in extension storage. They are not synced by TextHelper. Credentials are not encrypted by a dedicated password manager. Valid Google translations may be cached in background memory for up to five minutes; that cache is not written to disk. Temporary design confirmations are kept in session storage, expire after five minutes and are removed on cancellation or submission. They do not contain API keys. A request made to a provider is subject to that provider's retention policies; TextHelper cannot delete the provider's records.

Control

You can disable the panel, choose services, delete saved API keys and remove hidden sites in the popup. Closing a confirmation without sending makes no design request. Uninstalling removes the extension's local settings. This release does not run in private browsing windows. No content is sent automatically on installation.

Permissions

Website access displays the selection toolbar. Storage saves your configuration; clipboardWrite supports explicit copying and optional automatic copying of completed results. API host permissions allow the configured requests. A custom API host requires a user-triggered permission request. Remote APIs use HTTPS; HTTP is accepted only for localhost or 127.0.0.1. No remote executable code is loaded.
