# TextHelper

**TextHelper** — расширение для работы с текстом: перевод, исправление и копирование выделенного текста.

## Версия

Chrome: **10.0.14** (Manifest V3, Chrome 109+).

## Установка в Google Chrome

1. Скачайте ZIP репозитория через **Code → Download ZIP** и распакуйте его.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку с файлом `manifest.json`.

## Настройки и провайдеры

Поддерживаются сервисы перевода и проверки текста, а также API-провайдеры, среди которых OpenAI, Anthropic Claude, DeepSeek, Google Gemini и OpenRouter. Для использования отдельных API могут потребоваться собственные ключи и оплата по тарифу провайдера.
